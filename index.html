Build & Deployment Instructions

Clone the open-source repository and launch the full agent harness in minutes.

github.com/ShawCole/bionic-agent-harness
1

Local Inference Engine (MLX / llama.cpp)

Start the open-weight coding model with optimized KV caching:

# Clone repo & setup Python venv
git clone https://github.com/ShawCole/bionic-agent-harness.git
cd bionic-agent-harness && python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
# Run Apple MLX server (Qwen 2.5 Coder 32B)
python -m mlx_lm.server --model mlx-community/Qwen2.5-Coder-32B-Instruct-4bit --port 1234
2

Autonomous Agent Loop & Tool Broker

Run the autonomous agent controller with file diffing and sandboxed bash:

# Launch Agent Core against local workspace
python src/agent_core.py --workspace . --model-endpoint http://localhost:1234/v1
# Run offline Voxtral speech-to-text service
python src/voxtral_stt.py --port 8765
3

Desktop Workspace (Tauri v2 + React)

Launch the visual workspace with bidirectional Excalidraw sync:

# Build & run desktop application
cd web && npm install
npm run tauri dev
# Package native desktop binary (.dmg / .app / .deb)
npm run tauri build
4

Deploy Interactive Deliverable to Netlify

Publish the interactive deliverable to Netlify with single-command deployment:

# Deploy static deliverable to Netlify
npx netlify-cli deploy --prod --dir .
# Live URL configured:
https://viorel-bionic-teardown.netlify.app
